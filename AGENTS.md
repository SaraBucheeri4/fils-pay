# AI agent conventions — FilsPay

The rules for every coding agent (Claude, Cursor, Copilot, Codex, etc.) are
in [CLAUDE.md](CLAUDE.md). Read that file. This one only points to it, so
there is a single source to keep accurate.

Short version: money is integer fils (1 BD = 1000), the business day is
Asia/Bahrain, and ADRs plus `docs/ARCHITECTURE.md` define intended behaviour.
Comments, HANDOVER, CHANGELOG and commit messages are unverified until
checked against the code.
